# National Sorghum Producers — Analytical Tools & Dashboards

This repository contains interactive dashboards, analytical tools, and related outputs developed by Carbon A List (CAL) in collaboration with National Sorghum Producers (NSP).

The tools are intended to support analysis and decision-making related to sorghum production, agricultural economics, water use, feed resilience, and other issues affecting producers in the High Plains.

## Current Tools

### Sorghum Partial Budget Analysis

An interactive dashboard for comparing the economics of sorghum and alternative cropping systems across selected regions, irrigation regimes, and years.

The dashboard draws from publicly available extension cost-and-return budgets, including:

- Texas A&M AgriLife Extension
- Kansas State University AgManager.info

Users can compare variables such as:

- Revenue
- Variable and fixed costs
- Returns above variable costs
- Returns above specified costs
- Irrigation water applied
- Returns per acre-inch of water
